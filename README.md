## 광고 캠페인 리포트 대시보드 (깃허브 없이 사용 가능)

엑셀(`.xls`, `.xlsx`) 또는 CSV 파일을 올리면 캠페인별/일자별 성과표와 그래프를 자동 생성합니다.

## 빠른 실행

```bash
pip install -r requirements.txt
python run_dashboard.py
```

실행 후 브라우저에서 `http://localhost:8501` 접속하세요.

## 이번 버전 주요 기능

- `xls/xlsx/csv` 업로드 지원 (`.xls` 포함)
- 엑셀 1행/1열 공란 케이스 대응 (헤더 2행 인식 우선)
- 캠페인명에서 `광고주명`, `광고상품`, `기기구분(MO/PC/공통, 모바일→MO)` 자동 분류
- 일자별 추이 그래프: **좌측축=노출수, 우측축=총클릭수+동영상조회수**
- CTR 그래프 단순화: `CTR(전체)` + `VTR`만 표시
- 테이블 값에 전체 대비 비중 표기 (예: `10,000 (35.2%)`)
- 광고주 보고용 PDF 다운로드 버튼 추가

## 필수 컬럼

`광고계정`, `회사`, `캠페인명`, `일자`, `노출수`, `클릭수`, `컴패니언배너클릭수`, `동영상조회수`, `CTR`, `CTR(전체)`, `VTR`, `광고비`, `eCPM`, `CPC`, `CPV`
