## 광고 캠페인 리포트 대시보드

엑셀(`.xls`, `.xlsx`) 또는 CSV를 업로드하면 광고주 보고용 대시보드와 PDF를 자동 생성합니다.

## 빠른 실행

```bash
pip install -r requirements.txt
python run_dashboard.py
```

## 주요 기능

- 노출수 0인 일자는 자동 제외, 해당 일자만 분석기간으로 사용
- 캠페인명 파싱: `광고주명`, `광고상품`, `기기구분(MO/PC/공통)`
- 일자 추이 이중축: 좌측(노출수), 우측(총클릭수/조회수)
- 캠페인별 요약 + 광고상품/기기별 요약 테이블
- 캠페인 효율 요약(TOP3 노출수, TOP3 CTR)
- 캠페인별 광고일수 표시
- 테이블 값에 전체 대비 비중 표시
- 흰색 배경 시각화 포함 PDF 다운로드

## 필수 컬럼

`광고계정`, `회사`, `캠페인명`, `일자`, `노출수`, `클릭수`, `컴패니언배너클릭수`, `동영상조회수`, `CTR`, `CTR(전체)`, `VTR`, `광고비`, `eCPM`, `CPC`, `CPV`
