## 광고 캠페인 리포트 대시보드 (깃허브 없이 사용 가능)

엑셀(`.xlsx`) 파일만 올리면, 캠페인별/일자별 성과 표와 그래프를 자동으로 만들어주는 프로그램입니다.

---

## 1) 가장 쉬운 사용 방법 (처음 써보는 분용)

아래 파일 4개를 **같은 폴더**에 두세요.

- `app.py`
- `run_dashboard.py`
- `requirements.txt`
- (선택) `README.md`

그다음 터미널(명령 프롬프트)에서 해당 폴더로 이동 후 아래 순서대로 실행:

```bash
pip install -r requirements.txt
python run_dashboard.py
```

실행되면 브라우저에 대시보드가 열립니다. (안 열리면 `http://localhost:8501` 접속)

---

## 2) 화면에서 하는 일

1. 왼쪽 사이드바에서 엑셀 파일 업로드
2. 기간/회사/캠페인 필터 선택
3. 아래 내용 자동 확인
   - 핵심 지표 카드(총 노출, 총 클릭, 평균 CTR, 총 광고비)
   - 일자별 추이 그래프
   - 캠페인별 요약 테이블
   - 일자별 상세 테이블
4. `캠페인 요약 CSV 다운로드` 버튼으로 파일 저장

---

## 3) 엑셀 필수 컬럼

아래 컬럼명이 정확히 있어야 합니다.

`광고계정`, `회사`, `캠페인명`, `일자`, `노출수`, `클릭수`, `컴패니언배너클릭수`, `동영상조회수`, `CTR`, `CTR(전체)`, `VTR`, `광고비`, `eCPM`, `CPC`, `CPV`

---

## 4) 자주 발생하는 문제

- `pip` 명령이 안 될 때
  - Python 설치가 안 되었거나 PATH 설정 문제일 수 있습니다.
  - Windows: `py -m pip install -r requirements.txt` 도 시도해보세요.

- 실행했는데 페이지가 안 열릴 때
  - 주소창에 `http://localhost:8501` 직접 입력
  - 사내 보안 프로그램/방화벽이 막는지 확인

- 컬럼 오류가 날 때
  - 컬럼명 앞뒤 공백, 오탈자 확인
  - 날짜 컬럼(`일자`)이 날짜 형식인지 확인

---

## 5) 개발자용 직접 실행

```bash
streamlit run app.py
```
